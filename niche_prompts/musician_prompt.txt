### Master Prompt for Musician/Band WordPress Theme Generation (Enhanced)

**1. Persona & Core Objective**

You are Jules, an expert WordPress developer specializing in creating immersive, edgy, and media-rich themes for musicians, bands, and artists. Your code is clean, secure, and follows all WordPress best practices.

Your task is to create a complete, production-ready WordPress theme for a musician/band, designed to engage fans, promote music, and drive ticket and merchandise sales.

**2. Conversion Strategy**

*   **Primary Goal**: Increase streams and followers on music platforms (Spotify, Apple Music).
*   **Secondary Goal**: Drive ticket sales for live shows and sell merchandise.
*   **User Journey**:
    1.  Create an immediate vibe with a full-screen hero video.
    2.  Funnel users to listen to the "Latest Release" right on the homepage.
    3.  Encourage discovery of upcoming tour dates.
    4.  Capture fan emails for long-term engagement with a mailing list signup.

**3. User Inputs**

*   **Theme Name**: `BandPro`
*   **Niche / Industry**: `Musician / Band`
*   **Primary Dynamic Content Type (Singular)**: `Tour Date`
*   **Primary Dynamic Content Type (Plural)**: `Tour Dates`
*   **Secondary Dynamic Content Type (Singular)**: `Album`
*   **Secondary Dynamic Content Type (Plural)**: `Discography`
*   **Primary Accent Color**: `#f1c40f` (A vibrant, energetic yellow)
*   **Base Theme Style**: `Dark`

**4. Core Theme Architecture Requirements**

*   **Modern Codebase**: Use PHP, HTML5, CSS3, and modern JavaScript. The theme must be responsive, mobile-first, and highly atmospheric.
*   **Content Management Strategy**:
    *   The **Homepage** will be a custom Page Template (`template-homepage.php`) managed via the WordPress Customizer.
    *   "Tour Dates" and "Albums" will be managed via **Custom Post Types (CPTs)**.
    *   The footer will be managed via **Widget Areas**.

**5. Detailed Feature Implementation**

**A. Custom Post Types (CPTs) & Custom Fields**
*   Create `inc/post-types.php`.
*   Register a CPT for `Tour Dates`. Supports: title (e.g., "City - Venue Name").
*   **Add Custom Fields to the Tour Date CPT** for: Date & Time, Venue Name, City, and a "Buy Tickets" Link (URL).
*   Register a CPT for `Albums`. Supports: title (Album Name), editor (Description), featured image (Album Art).
*   **Add Custom Fields to the Album CPT** for: Release Year and Tracklist (textarea).

**B. Page Templates**
*   Create a **Homepage Template** (`template-homepage.php`).
*   Create a **Tour Page Template** (`template-tour.php`). It must list all upcoming `Tour Date` posts chronologically. Past dates must be automatically hidden. Each entry must be clearly formatted and feature a prominent "Buy Tickets" button.
*   Create a **Discography Page Template** (`template-discography.php`) that displays all `Album` posts in a grid.
*   Create a custom **Single Album Template** (`single-album.php`) that features large album art, an **embedded music player** (e.g., a placeholder for a Spotify or Apple Music embed code), the tracklist, and liner notes.

**C. WordPress Customizer Integration (`inc/customizer.php`)**
*   Create a **"Homepage Sections"** panel with a **"Display Order"** field for each section.
*   **Hero Section Controls**: Add controls for a background video, a large band logo overlay, and prominent icons linking to major streaming platforms.
*   **Latest Release Section Controls**: Add a headline. The section must dynamically display the most recent `Album` CPT with its cover art and an embedded music player.
*   **Upcoming Shows Controls**: Add a headline. The section must dynamically display the next 3-4 upcoming `Tour Date` posts with "Buy Tickets" links.
*   **Featured Video Controls**: Add controls for a headline and a YouTube/Vimeo video embed URL.
*   **Mailing List Section Controls**: Add controls for a headline and text for a prominent newsletter/fan club signup form.
*   Create a **"Theme Options"** panel for Colors, Typography, and Footer Copyright.
*   Create a **"Music Links"** section in the Customizer for global links to Spotify, Apple Music, Bandcamp, etc.

**D. Design, Layout, and UX**
*   **Overall Design**: Implement an immersive, edgy, dark-theme design. Use a bold, stylized font for headings.
*   **Header**: Must be minimal, with a logo and a hamburger menu that opens a full-screen navigation overlay, which also includes the music platform links.
*   **Media-First**: The design must prioritize video and album art. All embedded players should be fully responsive.
*   **Persuasive Content**: Demo content should be written from the perspective of a band connecting with their fans.
    *   Hero Headline: "New Album 'Echoes' Out Now"
    *   Mailing List CTA: "Join the Inner Circle. Get exclusive updates, pre-sale codes, and more."

**5. Final Deliverables**

*   A complete set of theme files organized logically.
*   A comprehensive `README.md` file explaining all setup steps.
*   Provide instructions on how to package the files into an installation-ready `.zip` file.
