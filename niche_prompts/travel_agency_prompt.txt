### Master Prompt for Travel Agency WordPress Theme Generation (Enhanced)

**1. Persona & Core Objective**

You are Jules, an expert WordPress developer specializing in creating vibrant, inspiring, and feature-rich themes for the travel and tourism industry. Your code is clean, secure, and follows all WordPress best practices.

Your task is to create a complete, production-ready WordPress theme for a travel agency, designed to inspire wanderlust and convert visitors into booked clients.

**2. Conversion Strategy**

*   **Primary Goal**: Generate booking inquiries via a "Book This Tour" or "Request a Quote" form.
*   **Secondary Goal**: Encourage exploration of destinations and tour packages.
*   **User Journey**:
    1.  Inspire visitors with a stunning, full-screen hero video.
    2.  Allow users to immediately start filtering for their dream vacation on the homepage.
    3.  Showcase popular destinations and featured tours to guide user choice.
    4.  Convert users on a highly detailed and persuasive single tour page.

**3. User Inputs**

*   **Theme Name**: `TravelPro`
*   **Niche / Industry**: `Travel Agency`
*   **Primary Dynamic Content Type (Singular)**: `Tour`
*   **Primary Dynamic Content Type (Plural)**: `Tours`
*   **Secondary Dynamic Content Type (Singular)**: `Destination`
*   **Secondary Dynamic Content Type (Plural)**: `Destinations`
*   **Primary Accent Color**: `#1abc9c` (A vibrant, fresh teal)
*   **Base Theme Style**: `Light`

**4. Core Theme Architecture Requirements**

*   **Modern Codebase**: Use PHP, HTML5, CSS3, and modern JavaScript. The theme must be responsive, mobile-first, and highly visual.
*   **Content Management Strategy**:
    *   The **Homepage** will be a custom Page Template (`template-homepage.php`) managed via the WordPress Customizer.
    *   "Tours" and "Destinations" will be managed via **Custom Post Types (CPTs)**.
    *   The "Tour" CPT will have extensive custom fields and be categorized by multiple custom taxonomies.
    *   The footer will be managed via **Widget Areas**.

**5. Detailed Feature Implementation**

**A. Custom Post Types (CPTs) & Taxonomies**
*   Create `inc/post-types.php`.
*   Register a CPT for `Tours`. Supports: title, editor, featured image.
*   **Add Custom Fields to the Tour CPT** for: Price, Duration, a detailed day-by-day Itinerary (repeater field), and a Photo Gallery (multiple image uploads).
*   Register a CPT for `Destinations`. Supports: title, editor, featured image.
*   Register two custom taxonomies for the `Tour` post type: `Location` (to link to `Destination` posts) and `Travel Style` (e.g., "Adventure", "Luxury", "Family").

**B. Page Templates**
*   Create a **Homepage Template** (`template-homepage.php`).
*   Create a **Tours Page Template** (`template-tours.php`). This template must display all `Tour` posts in a grid and **must include AJAX-powered filter controls** for `Location`, `Travel Style`, price range, and duration.
*   Create a custom **Single Tour Template** (`single-tour.php`). This key conversion page must feature:
    *   A hero section with a slider/gallery of the best tour photos.
    *   A **sticky sidebar** that scrolls with the user, containing key details (Price, Duration) and a prominent "Book This Tour" inquiry form.
    *   A tabbed interface for "Description", "Itinerary", and "Map".

**C. WordPress Customizer Integration (`inc/customizer.php`)**
*   Create a **"Homepage Sections"** panel with a **"Display Order"** field for each section.
*   **Hero Section Controls**: Add controls for a background video, a headline (e.g., "Your Next Adventure Awaits"), and a detailed tour search/filter UI.
*   **Popular Destinations Controls**: Add a headline. Dynamically display 4-6 featured `Destination` posts.
*   **Featured Tours Controls**: Add a headline. Dynamically display 3-4 featured `Tour` posts in a carousel.
*   **Why Choose Us Section**: Add a section with controls for 3-4 icon+text blocks to highlight company value propositions (e.g., "Expert Guides", "Custom Trips").
*   **Testimonials & CTA Section Controls**: Add controls for these standard sections.
*   Create a **"Theme Options"** panel for Colors, Typography, and Footer Copyright.

**D. Design, Layout, and UX**
*   **Overall Design**: Implement a vibrant, clean, and inspiring design that uses high-impact photography.
*   **Header**: Must include a logo, primary navigation, and social media links.
*   **Tour Filtering**: The AJAX filtering on the tours page must be fast and smooth.
*   **Image Galleries**: All photo galleries must use a lightbox for an immersive experience.
*   **Persuasive Content**: Demo content should be exciting and inspiring.
    *   Hero Headline: "Discover the World, Unforgettable."
    *   Tour Title: "The Ultimate 10-Day Safari in Tanzania"

**5. Final Deliverables**

*   A complete set of theme files organized logically.
*   A comprehensive `README.md` file explaining all setup steps.
*   Provide instructions on how to package the files into an installation-ready `.zip` file.
