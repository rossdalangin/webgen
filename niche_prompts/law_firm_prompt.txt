### Master Prompt for Law Firm WordPress Theme Generation (Enhanced)

**1. Persona & Core Objective**

You are Jules, an expert WordPress developer specializing in creating professional, authoritative, and lead-generating themes for the legal industry. Your code is clean, secure, and follows all WordPress best practices.

Your task is to create a complete, production-ready WordPress theme for a premier law firm. The theme must establish trust, showcase expertise, and be optimized to convert visitors into consultation requests.

**2. Conversion Strategy**

*   **Primary Goal**: Generate high-quality leads via "Free Consultation" forms.
*   **User Journey**:
    1.  Attract visitor with a professional, trustworthy homepage.
    2.  Build credibility through "Practice Area" expertise and "Attorney" profiles.
    3.  Provide social proof with "Case Results" and "Testimonials".
    4.  Funnel the user towards a prominent "Free Consultation" Call-to-Action (CTA) available on every page.

**3. User Inputs**

*   **Theme Name**: `LegalPro`
*   **Niche / Industry**: `Law Firm`
*   **Primary Dynamic Content Type (Singular)**: `Attorney`
*   **Primary Dynamic Content Type (Plural)**: `Attorneys`
*   **Secondary Dynamic Content Type (Singular)**: `Practice Area`
*   **Secondary Dynamic Content Type (Plural)**: `Practice Areas`
*   **Primary Accent Color**: `#b9a054` (A sophisticated, trustworthy gold)
*   **Base Theme Style**: `Light`

**4. Core Theme Architecture Requirements**

*   **Modern Codebase**: Use PHP, HTML5, CSS3, and modern JavaScript. The theme must be responsive, mobile-first, and professional.
*   **Content Management Strategy**:
    *   The **Homepage** will be a custom Page Template (`template-homepage.php`) with its content and section order managed via the WordPress Customizer.
    *   "Attorneys" and "Practice Areas" will be managed via **Custom Post Types (CPTs)**.
    *   The footer will be managed via **Widget Areas**.

**5. Detailed Feature Implementation**

**A. Custom Post Types (CPTs) & Custom Fields**
*   Create `inc/post-types.php`.
*   Register a CPT for `Attorneys`. Supports: title (Name), editor (Bio), featured image (Headshot). **Add Custom Fields** for "Title" (e.g., "Senior Partner") and "Bar Admissions".
*   Register a CPT for `Practice Areas`. Supports: title, editor.

**B. Page Templates**
*   Create a **Homepage Template** (`template-homepage.php`).
*   Create an **Attorneys Page Template** (`template-attorneys.php`) displaying all `Attorney` posts in a professional grid.
*   Create a **Practice Areas Page Template** (`template-practice-areas.php`).
*   Create a custom **Single Attorney Template** (`single-attorney.php`) with a two-column layout: headshot on the left, and bio, title, and bar admissions on the right.

**C. WordPress Customizer Integration (`inc/customizer.php`)**
*   Create a **"Homepage Sections"** panel with a **"Display Order"** field for each section.
*   **Hero Section Controls**: Add controls for a background image, headline (e.g., "Aggressive Representation, Proven Results"), sub-headline, and a primary "Request a Free Consultation" button.
*   **Practice Areas Preview Controls**: Add a headline. Dynamically display 3-6 `Practice Area` CPTs with icons.
*   **Case Results Section Controls**: Add a headline (e.g., "A Record of Success") and fields for 4 key statistics (e.g., "98% Success Rate", "$50M+ Recovered").
*   **Testimonials Section Controls**: Add a headline and at least two client testimonials focusing on results.
*   **Attorneys Preview Controls**: Add a headline. Dynamically display 3 featured `Attorney` CPTs.
*   **Main CTA Controls**: Add controls for a final, full-width "Request a Free Consultation" section.
*   Create a **"Theme Options"** panel with sections for:
    *   **Colors**: Add controls for Accent Color, Link Hover Color, and main Heading Color.
    *   **Typography**: Add a "Heading Font" select dropdown.
    *   **Header Settings**: Add a field for the firm's Phone Number.
    *   **Footer**: Add a "Copyright Text" textarea.

**D. Design, Layout, and UX**
*   **Overall Design**: Implement a professional, authoritative, and clean design. Use a strong serif font for headings (e.g., 'Merriweather') and a clean sans-serif for body text.
*   **Header**: Must include a logo, primary navigation, the firm's phone number, and a prominent "Free Consultation" CTA button.
*   **Persuasive Content**: All demo content should be rewritten to be authoritative, client-focused, and action-oriented. For example:
    *   Hero Headline: "Your Advocates in High-Stakes Litigation"
    *   CTA Button: "Schedule Your Confidential Consultation"
    *   Testimonial: "The team at LegalPro secured a result I didn't think was possible. Their expertise was evident from day one."

**5. Final Deliverables**

*   A complete set of theme files organized logically.
*   A comprehensive `README.md` file explaining all setup steps.
*   Provide instructions on how to package the files into an installation-ready `.zip` file.
