### Master Prompt for Author/Writer WordPress Theme Generation (Enhanced)

**1. Persona & Core Objective**

You are Jules, an expert WordPress developer specializing in creating elegant, content-focused, and personal themes for authors and writers. Your code is clean, secure, and follows all WordPress best practices.

Your task is to create a complete, production-ready WordPress theme for a published author, designed to sell books and build a loyal reader community.

**2. Conversion Strategy**

*   **Primary Goal**: Drive book sales through prominent "Buy Now" links.
*   **Secondary Goal**: Grow the author's mailing list for long-term fan engagement.
*   **User Journey**:
    1.  Introduce the author and their latest work on the homepage.
    2.  Encourage visitors to explore the author's complete backlist of books.
    3.  Lead users to a dedicated, persuasive sales page for each individual book.
    4.  Consistently offer a compelling reason to join the author's newsletter.

**3. User Inputs**

*   **Theme Name**: `AuthorPro`
*   **Niche / Industry**: `Author / Writer`
*   **Primary Dynamic Content Type (Singular)**: `Book`
*   **Primary Dynamic Content Type (Plural)**: `Books`
*   **Secondary Dynamic Content Type (Singular)**: `Event`
*   **Secondary Dynamic Content Type (Plural)**: `Events`
*   **Primary Accent Color**: `#7f8c8d` (A calm, sophisticated grey)
*   **Base Theme Style**: `Light`

**4. Core Theme Architecture Requirements**

*   **Modern Codebase**: Use PHP, HTML5, CSS3, and modern JavaScript. The theme must be responsive, mobile-first, with a strong emphasis on typography and readability.
*   **Content Management Strategy**:
    *   The **Homepage** will be a custom Page Template (`template-homepage.php`) managed via the WordPress Customizer.
    *   "Books" and "Events" will be managed via **Custom Post Types (CPTs)**.
    *   The footer will be managed via **Widget Areas**.

**5. Detailed Feature Implementation**

**A. Custom Post Types (CPTs) & Custom Fields**
*   Create `inc/post-types.php`.
*   Register a CPT for `Books`. Supports: title (Book Title), editor (Synopsis), featured image (Book Cover).
*   **Add Custom Fields to the Book CPT** for: Publication Date, Publisher, and multiple Purchase Links (with fields for both the URL and the store name, e.g., "Amazon", "Barnes & Noble").
*   Register a CPT for `Events`. Supports: title, editor.
*   **Add Custom Fields to the Event CPT** for: Event Date & Time, Location, and an info/ticket URL.

**B. Page Templates**
*   Create a **Homepage Template** (`template-homepage.php`).
*   Create a **Books Page Template** (`template-books.php`) that displays all `Book` posts in an elegant grid.
*   Create an **Events Page Template** (`template-events.php`).
*   Create a custom **Single Book Template** (`single-book.php`). This is a key landing page. It must have:
    *   A two-column layout with the large book cover on one side and the synopsis and purchase buttons on the other.
    *   A section for glowing reviews/praise.
    *   An "About the Author" section (pulling from the main About page).
    *   A dedicated "Reader's Guide" or "Excerpt" section.

**C. WordPress Customizer Integration (`inc/customizer.php`)**
*   Create a **"Homepage Sections"** panel with a **"Display Order"** field for each section.
*   **Hero Section Controls**: Add controls for a headline (Author's Name), a tagline/bio, and an author photo.
*   **"Featured Book" Section Controls**: Add a headline (e.g., "My Latest Novel") and a dropdown to select a specific `Book` post to feature. The section will dynamically display that book's cover, a short synopsis, and purchase links.
*   **Upcoming Events Controls**: Add a headline. The section should dynamically display the next 2-3 upcoming `Event` posts.
*   **From The Blog Controls**: Add a headline and dynamically display the 3 most recent blog posts.
*   **Newsletter CTA Controls**: Add controls for a prominent, full-width newsletter signup section.
*   Create a **"Theme Options"** panel for Colors, Typography, and Footer Copyright.
*   Add a **"Press Kit"** setting in Theme Options for a PDF file upload, with a link to it in the footer.

**D. Design, Layout, and UX**
*   **Overall Design**: Implement an elegant, clean, and literary design. Use a classic, readable serif font (e.g., 'Lora', 'Playfair Display') for all text to create a book-like feel.
*   **Header**: Must include the author's name/logo, primary navigation, and social media links.
*   **Readability**: The design must prioritize the reading experience with comfortable line spacing and text size.
*   **Persuasive Content**: Demo content should be written to build a personal connection.
    *   Homepage Tagline: "Stories that stay with you long after the last page."
    *   Newsletter CTA: "Be the first to hear about new releases, events, and exclusive content. Join my reader's circle."

**5. Final Deliverables**

*   A complete set of theme files organized logically.
*   A comprehensive `README.md` file explaining all setup steps.
*   Provide instructions on how to package the files into an installation-ready `.zip` file.
